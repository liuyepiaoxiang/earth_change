# ADR-003：v2 ESM-lite 耦合策略——全球聚合箱先行、弱反馈参数化、重校准不放宽门禁

| 项目 | 内容 |
|---|---|
| 状态 | accepted（V2-01 定稿并随本 ADR 进入实施） |
| 日期 | 2026-10-11 |
| 决策人 | earth-change（单人项目，AI 起草） |
| 背景 | v2 引入植被/火灾/冻土（eq_18, 33–40）需要：a) 状态向量扩展；b) 与 CO₂ 收支的耦合深度；c) 耦合后 G1–G5 校准策略。耦合式实现会改变模拟轨迹，是 v2 的核心风险 |

## 备选方案与决策

| 子决策 | 备选 | 决策 |
|---|---|---|
| D1 状态粒度 | (a) 真 2D 格点积分 (b) 全球聚合箱 | **(b) 聚合箱先行**：EarthState 增 4 个标量箱（bio.biomass、pedo.soil_moisture、cryosphere.permafrost_carbon + 已融池、cryosphere.snow_mass）。格点积分的性能/确定性风险大，SPEC §5.6 的 GridField 语义已在降水/高程诊断纹理上兑现，状态积分留 v2 后期 |
| D2 碳耦合深度与双重计入 | (a) 用植被箱**替代** eq_16 对数陆地汇（NPP−Rh 完整重建） (b) 新通量作为**气候驱动异常**叠加在 eq_16 之上 | **(b) 异常叠加**：GCP/GCB 排放已隐含基线火灾与土壤呼吸——显式箱若全额叠加即双重计入。新通量只建模**超出基线的气候反馈**：火灾异常 ΔFire = fire_k·ΔT·V·B/B₀；冻土释放 = r_pf·P_thawed（P_thawed 由超阈值融化累积，历史期近似 0）。基线火灾/呼吸留在 GCP 排放与对数汇内 |
| D3 新参数与校准 | (a) 新参数进入 Nelder-Mead 校准 (b) 新参数**固定为先验中心**，只重校准原参数 | **(b)**：参数空间 12→19 会显著增加校准不稳定风险；新反馈先验中心设为弱反馈（历史期影响小），其不确定性交由 V1-01 的 MC 扰动（PERTURBED_IDS 扩展）呈现——校准管拟合，MC 管不确定性 |

## 状态向量与耦合方程（v2 落地口径）

```
新增箱（EarthState 扩展，初值）：
  b (biomass, GtC)                B₀ = 550（植被生物量观测量级）
  w (soil moisture, mm)           W₀ = 800
  mPf (permafrost carbon, GtC)    M₀ = 1400（NCSCD 量级 ~1500）
  pTh (thawed pool, GtC)          0
  msnow (snow, mm we)             由 eq_24 诊断积分

耦合通量（全部为超出 GCP 基线的气候反馈）：
  dW/dt  = P_land(ΔT) − E_land(ΔT) − R      （eq_19–22，水循环箱）
  dB/dt  = NPP − R_h − ΔFire                （eq_18：NPP = npp_max·V·fT·fCO2，V = B/B₀）
  ΔFire  = fire_k·ΔT·V                      （eq_38 异常口径）
  dMpf/dt = −k_pf·max(ΔT − t_pf, 0)         （eq_39）
  dPth/dt = −dMpf/dt；E_pf = r_pf·pTh       （eq_40，CO₂ 份额 1.0 简化，CH₄ 份额注记忽略）
  eq_15 排放侧 += E_pf + ΔFire              （v2 耦合点）
  eq_16 陆地汇 += k_B·(B − B₀)·(1/B₀)?      否——B 影响仅通过 ΔFire/反照率诊断，
  陆地汇保持 eq_16 对数形式（避免双重计入），eq_16 注记 v2 不变
```

## 重校准与验收策略

1. **新参数固定为先验中心**（npp_max=50、r_heterotroph=0.045、fire_k=0.3、k_pf=30、t_pf=1.0、r_pf=0.02），不进 Nelder-Mead
2. 原参数重校准：新通量在历史期（ΔT≤1.4）量级小（冻土 ≈0、火灾异常 <0.5 GtC/yr），预期 β_L/γ 等微调即可过 G1–G3；**G2（CO₂ <5ppm）与 G4（AR6 区间）为硬门**
3. **新验收门 G6**（golden.test 扩展）：a) 冻土碳库量级 [1200, 1600] GtC（2500 年不出现负库/爆库）b) 植被分数 [0.5, 1.5]×B₀ c) 火灾异常单调随 ΔT d) 碳守恒扩展（E_pf + ΔFire 计入收支残差 <1%）
4. MC 扰动扩展：PERTURBED_IDS += fire_k, k_pf, r_pf（不确定性呈现）
