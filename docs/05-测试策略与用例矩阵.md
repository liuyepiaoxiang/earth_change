# 05-测试策略与用例矩阵

> 现状：120 条自动化测试全绿（spec 19 / data 12 / engine 69 / web 20）+ Playwright E2E 5 条（CI 内置）。

## 1. 分层职责

| 层 | 范围 | 框架 | 原则 |
|---|---|---|---|
| 单元测试 | 方程纯函数、插值/钳制、色阶编码、校验函数、状态机、数据校验、MC 采样 | vitest（各包） | 每个功能卡至少 1 条；纯函数、无 IO |
| 集成/验收 | 跨层契约：规格↔代码一致性、数据↔manifest、端到端模拟物理对标 | vitest | golden G1–G5 是 CI 门禁，禁放宽 |
| E2E | 浏览器完整链路（API 契约/交互/图层回归） | Playwright（`apps/web/e2e/`，CI 内置） | 画布视觉与坐标点选仍走手工冒烟 |
| 手工冒烟 | 每次发版前浏览器清单（本档 §5） | 人工/浏览器自动化辅助 | 10 分钟内完成 |

## 3. 状态转换测试表

### 3.1 图层布尔状态（F06）

| 动作 | 起始 | 目标 | 合法性 | 验证 |

| 点击任一图层 | 开 | 关 | ✅ | R1：面板态 + 视觉消失 |

## 4. 测试执行规范（改动类型 → 必跑）

| 改动 | 必跑 |
|---|---|
| `packages/spec/*.yaml` | `pnpm gen:spec && pnpm test`（一致性门禁会拦截未注册方程） |
| `packages/engine/**` | `pnpm --filter @future-earth/engine test`（golden 全量） |
| `packages/data/datasets/**` 或 `scripts/**` | `gen-bundle.mjs` + `pnpm --filter @future-earth/data test` |
| `apps/web/**` | `pnpm --filter web test && typecheck && build` |
| 任何 PR/推送 | CI 全量（install → gen:spec → typecheck → test → build） |

失败处理：本任务引入的失败必须修复后提交；历史失败如实记录不顺手改；禁止删断言/跳过用例掩盖问题。
