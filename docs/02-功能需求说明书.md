## 3. 状态机

### 3.1 页面数据状态（app/page.tsx）

```
loading（引擎动态加载/模拟中） ──成功──→ ready（sim + snapshot 可用）
        │                                    │ 切情景 → 回到 loading（缓存命中则瞬时 ready）
        └──失败──→ error（展示错误信息，无重试按钮，刷新页面恢复）
```

### 3.2 图层状态（LayerState，5 个独立布尔位）

任意组合合法；温度/城市影响 points 数组重建，淹没/大气改 uniform，底图改材质 map。非法状态不存在。

### 3.3 模拟拼接状态（engine）

历史段（1851–2024 排放驱动）与情景段（2025–horizon 浓度驱动）拼接；horizon ∈ [2026, 2500] 整数，越界由 zod 拒绝（API）。

## 4. 非功能需求

| 项 | 要求 | 现状 |
|---|---|---|
| 确定性 | 同参数两次运行逐位一致（G5）；API 输出 immutable 缓存 | ✅ |
| 性能 | 单情景模拟毫秒级；时间轴拖动纯渲染 60fps；首包 ≤ 130KB | ✅（First Load 128KB） |
| 可离线打包 | 引擎与数据静态打包进 bundle，无运行时数据请求、无外部 CDN | ✅ |
| 可复现校准 | `pnpm calibrate` 重跑结果与入库 params.json 逐位一致 | ✅ |
| 物理对标 | G1–G5 五道定量验收门（历史复现 + AR6 区间 + 碳守恒） | ✅ |

## 5. 验收标准

1. `pnpm test` 全绿（含 G1–G5）+ `pnpm --filter web build` 成功（CI 同款）
2. 浏览器冒烟：切换 4 情景、拖时间轴两端、5 图层各开关两次、点击城市出面板、淹没随年份扩张
3. CLI 输出与 API 同年份指标一致（抽查 2100/2500）

- v1.x 收尾批：辐射收支诊断（eq_01–05）、单层对比（eq_10）、水循环箱链（eq_19–24）——全诊断式，G1–G5 逐位不变
