## 3. 联调顺序与最小可演示闭环

最小闭环 = F01 API + F02 时间轴 + F03 温度层（已达成）。后续任何新功能先保「API 可跑 → 图层可开关 → 浏览器冒烟清单通过」。

## 4. 风险与回滚

- 每任务一 commit，可独立 revert；校准/规格变更前先跑 `pnpm calibrate` 确认确定性不破
- 数据集变更必须连带 manifest + gen-bundle + loaders 测试三方同步，否则 CI 拦截
