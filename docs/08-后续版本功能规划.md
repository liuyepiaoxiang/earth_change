# 08-后续版本功能规划（v1 收尾批 → v2 ESM-lite → v3 地貌演化）

> 建立日期：2026-10-11 ｜ 版本：1.0 ｜ 依据：SPEC §4.4 方程分级 + §10 路线图 + ADR-001 诊断式先例
> 定位：**具体功能规划**——每个任务有编号、方程映射、实现口径、验收标准与测试映射；进入编码前按 07 文档流程做准入复核。
> 方程事实基线（2026-10-11）：53 条方程中已实现 25 条（v0 标记，21 耦合 + 3 海冰诊断 + eq_49–53 中 5 条降尺度已含于 21 计数）；未实现 28 条 = v1 层 11 + v2 层 9 + v3 层 8。

## 1. 范围协调（规格内部缺口修正）

SPEC §4.4 将 eq_10、19–24 列入 v1 层，但 §10 的 v1 版本行只列了 eq_01–05、28–30——**水循环组（19–24）与单层诊断（10）未归属任何版本行**。本规划裁决如下（需回填 SPEC §10 表）：

| 方程组 | 归属 | 实现模式 |
|---|---|---|
| eq_01–05 辐射能量平衡 | **v1.x 收尾批** | 诊断式（ADR-001 先例） |
| eq_10 单层温度响应 | **v1.x 收尾批** | 诊断式（与两层 EBM 并行对比） |
| eq_19–24 水循环 | **v1.x 收尾批**（格点化，复用 F12 降水格点） | 诊断式格点链 |
| eq_18、33–40 植被/火灾/冻土 | **v2** | 耦合式（触发 ADR-003 与重校准） |
| eq_41–48 地貌 | **v3** | 格点演化（依赖 v2 水循环+植被格点） |

## 2. v1.x 收尾批（✅ 2026-10-11 完成：V1-07/08/09）

**实现模式**：沿用 ADR-001——纯函数 + registry 注册 + YAML impl 改 v0 + 不接入 solver RHS + golden 逐位不变。UI 消费为新图层/面板。

### V1-07 辐射能量平衡显式诊断（eq_01–05）
- 新文件 `engine/equations/energy.ts`：`qIn(δS=0)` = (1361/4)；`qRef(α)` = α·Q_in；`qAbs(α)` = (1−α)·Q_in；`qOut(Te)` = ε·σ·Te⁴（ε=0.98，Te = 288.15+Ts）；`netRadiation` = Q_abs − Q_out
- 已知张力（记录进 ADR-001 附注）：显式收支的诊断值与 v0 隐式处理（forcing 数据 + 两层 EBM）**数值上不强行一致**——面板标注「显式能量收支（诊断口径）」
- UI：MetricsBar 或新增「能量收支」小面板（Q_in/Q_abs/Q_out/N 四值）
- 测试映射：Stefan-Boltzmann 校验点（Te=288.15K → Q_out≈390 W/m²）；平衡态 N≈0（取校准后 1850 状态）；registry 一致性自动覆盖
- YAML：eq_01–05 impl v1→v0（notes 注明诊断式）；gen:spec 后一致性门禁自动收紧

### V1-08 单层温度响应对比诊断（eq_10）
- `engine/equations/singlelayer.ts`：单层 EBM `Ca·dTa/dt = F − λ·Ta − γ(Ta−To)` 与两层模型**并行离线运行**，输出对比序列（不进 SimResult 主路径）
- UI：时间轴面板叠加「单层对比」虚线（可开关）
- 测试映射：ECS 解析校验（F₂ₓ/λ）；与两层模型残差有界（文档化差异，SPEC §4.4 已注记「v0 由 eq_11/12 涵盖」）

### V1-09 水循环诊断格点链（eq_19–24）
- 数据：直接复用 `precip_5min.png`（F12 已交付）为 P 基准场；温度场用 F03 的 pattern scaling（ΔT×纬度带）
- 新文件 `engine/equations/water.ts`：`evaporation(Ts)`（Magnus 饱和比湿差 × ke）；`precipitation(P0, ΔT)` = P0×(1+0.02ΔT)（与 eq_52 同式，格点化）；`waterBalance`/`runoff`/`soilMoisture` 桶模型（月步长离线诊断）；`snowBudget`（T<0 降水为雪，度日融化）
- 产出：土壤湿度/积雪**格点诊断纹理**（生成脚本离线产出，非运行时积分）→ 新 UI 图层「土壤湿度」「积雪」
- 测试映射：水量守恒（P = E + R + ΔW，年尺度残差 <1%）；雪线阈值（T>0 融化）；一致性与 registry 覆盖
- 验收：golden 全绿；新图层 E2E 循环；04 文档功能卡 F13–F15

**v1.x 验收门**：G1–G5 逐位不变（纯诊断）；测试总量 ≥ 135；02/03/04/05 文档同步。

## 3. v2 完整 ESM-lite（✅ 2026-10-11 完成：V2-01~09，重校准一次过门）

**前置决策 ADR-003（proposed，进入 V2-01 时定稿）**，三个子决策：
1. 状态向量扩展：EarthState 增 `bio.biomass`、`pedo.soil_moisture`、`cryosphere.permafrost_carbon`、`cryosphere.snow_mass`（SPEC §5.6 GridField 语义：**全球聚合箱先行，真格点积分留 v2 后期**——格点仅做诊断渲染，避免 4320×2160 状态积分的性能/确定性风险）
2. 碳循环耦合：eq_40 冻土释放与 eq_38 火灾**接入** eq_15 的排放项 → CO₂ 路径改变 → **触发重校准**
3. 植被-反照率：eq_29 的植被项保持诊断（耦合留 v3）

## 7. 测试与验收门策略（版本递进规则）

1. golden（G1–G5）语义恒定：**阈值永不放宽**；v2 耦合改变物理 → 重校准使其自然过门，过不了 = 耦合方案有问题（回 ADR-003 重新设计，不是调阈值）
2. 每版本可增验收门（G6 碳库/植被、G7 地貌守恒），门定义先于实现（测试先行）
3. 诊断式方程（ADR-001 模式）不触发重校准；耦合式必须
4. 每任务完成 = 功能卡（04）+ 测试映射 + 本档勾选 + commit
