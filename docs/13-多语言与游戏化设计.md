## 第一部分：多语言支持（i18n）

### 方案：轻量字典 + 运行时切换

不用 next-intl（太重），用简单的 `useLocale` hook + 字典对象。

```
lib/i18n/
  ├── types.ts          # TranslationKey 类型
  ├── zh.ts             # 中文字典（~200 条）
  ├── en.ts             # 英文字典（~200 条）
  └── index.ts          # useLocale() hook + LocaleContext
```

### 范围

| 层 | 内容 | 数量 |
|---|---|---|
| layout | title / description / OG | ~10 |
| Dashboard | header 按钮 / 工具提示 | ~15 |
| AnalysisDrawer | tab 名 | ~10 |
| 10 个面板 | 全部 UI 文本 | ~120 |
| CityPanel | 城市信息 / 群系名 | ~20 |
| 游戏/任务 | 题目 / 选项 / 反馈 | ~25 |

### 路由策略

`/?lang=en` 查询参数（不加 locale 前缀，保持 URL 简洁用于分享）
- 默认 zh-CN
- `localStorage` 记住选择
- `<html lang>` 动态更新

## 第二部分：SEO 增强 + GEO（生成式引擎优化）

### SEO 补充（在已有基础上）

| 项 | 做法 |
|---|---|
| 多语言 hreflang | `<link rel="alternate" hreflang="en" href="...?lang=en">` |
| FAQ Schema | 首页添加 FAQPage JSON-LD（6 个常见问题） |
| 如何到达 | HowTo Schema（「如何使用模拟器」步骤） |
| Breadcrumb | 面包屑导航（首页 → 分析 → 影响评估） |

### GEO（让 ChatGPT / Perplexity / Google AI 引用你的数据）

GEO 的核心：**让 AI 搜索引擎能提取结构化、可引用的事实**。

| 策略 | 实现方式 |
|---|---|
| **事实卡** | 每个关键页面有 `<Fact>` 组件：一句话 + 来源 + 数值（如「SSP2-4.5 在 2100 年升温约 2.8°C」） |
| **llms.txt** | `public/llms.txt`：告诉 AI 爬虫哪些页面可访问、数据结构是什么 |
| **结构化 FAQ** | FAQPage schema + 页面可见 FAQ 内容（AI 偏好提取 Q&A 格式） |
| **表格数据** | 关键数据用 HTML `<table>`（AI 解析表格最可靠） |
| **明确定义** | 页面上有「什么是 SSP？」「什么是辐射强迫？」等术语定义段落 |
| **来源引用** | 每个数据旁边标注来源（NASA / IPCC AR6）——AI 优先引用有来源的数据 |

### llms.txt 示例

```
# Future Earth Engine
> 5-500 year Earth climate evolution simulator

## Key Facts
- SSP2-4.5 warming by 2100: ~2.8°C (IPCC AR6)
- Sea level rise by 2100 (SSP2-4.5): ~0.7m
- Data sources: NASA GISTEMP, NOAA CO₂, IPCC AR6

## Pages
- / : Interactive 3D globe with timeline
- /overview : Model overview and guided tours
- /api/simulate : JSON API for simulation results

## Data freshness
- Historical data through 2024
- Auto-refreshed monthly via GitHub Actions
```

## 第三部分：游戏化与变现设计（参考 1in8b.life 模式）

### 1in8b.life 核心模式拆解

| 特征 | 1in8b 做法 | 我们可以借鉴的 |
|---|---|---|
| **个人化入口** | 「你是 80 亿分之几」→ 用户输入生日获得专属结果 | 「你的城市会怎样？」→ 输入城市名获得专属气候报告 |
| **即时惊喜** | 数字对比 + 可视化 + 出人意料的事实 | 拖动时间轴 → 里程碑事件弹出 + 城市淹没可视化 |
| **社交货币** | 精美分享卡（含个人数据）→ 用户主动传播 | 城市命运卡（含城市数据+未来预测）+ 实验结果卡 |
| **免费增值** | 基础免费 → 高级报告付费 | 基础模拟免费 → 高级功能订阅 |
| **低门槛** | 3 秒理解玩法，30 秒完成 | 拖时间轴 = 3 秒上手，看变化 = 30 秒 |

### 游戏化层级设计

```
层级 1：探索者（免费）
├── 3D 地球浏览 + 时间轴
├── 城市点击查询
├── 4 个 SSP 情景
├── 大事记 + 里程碑通知
└── 基础分享（链接 + 截图）

层级 2：实验者（免费注册）
├── 保存实验（5 个）
├── 学习任务 + 徽章
├── 猜猜看游戏 + 排行榜
├── 城市命运轮盘
├── 对比视图
└── 高级分享（PNG 卡片 + 数据卡片）

层级 3：分析师（Pro 订阅）
├── 无限实验保存
├── 自定义参数范围（超出默认先验）
├── 导出全量数据（CSV + JSON API）
├── 私人情景（不公开的实验）
├── API 密钥（第三方调用）
├── 无水印分享卡
├── 优先访问新功能
└── 教室/团队版（多用户管理）
```

### 变现设计

| 层 | 价格 | 内容 | 目标用户 |
|---|---|---|---|
| Free | ¥0 | 层级 1 全部 + 层级 2 部分 | 教育工作者/学生/好奇者 |
| Pro | ¥29/月 | 层级 3 全部 | 研究者/内容创作者/深度用户 |
| Classroom | ¥199/月 | Pro + 30 学生账号 + 教师面板 | 中学/大学课堂 |
| Enterprise | 联系 | 定制情景/私有部署/白标 | 企业 ESG/政府咨询 |

### 付费触发点（不是付费墙，是价值升级）

```
用户拖时间轴 → 看到 2100 年升温 2.8°C → 想知道更多
  → 点击「我的城市」→ 看到城市报告 → 想保存
  → 提示「注册保存」→ 注册 → 想自定义
  → 点击「实验室」→ 调参数 → 想保存多个
  → 提示「升级 Pro 保存更多」→ 付费
```

**关键原则**：免费层永远有用——付费只是解锁更多，不是从「没用」变「有用」。

### 分享卡设计（社交货币）

| 卡片类型 | 内容 | 触发时机 |
|---|---|---|
| 🏙️ 城市命运卡 | 城市名 + 当前/未来温度 + 淹没状态 + 年份 | 点击城市后 |
| 🧪 实验结果卡 | 你的实验参数 + 2100 结果 + 与基准差值 | 完成实验后 |
| 🎮 猜猜看成绩卡 | 你的分数 + 连对数 + 「你的气候直觉超过了 X% 的人」 | 游戏结束后 |
| 📊 对比卡 | A vs B 情景 + 差值 + 一句话结论 | 对比完成后 |
| 🏆 成就卡 | 徽章 + 完成日期 + 分享邀请 | 获得徽章时 |

### 付费墙设计（非阻断式）

```
┌────────────────────────────────────┐
│  📊 你已保存 3/5 个实验              │
│                                    │
│  [管理实验]  [升级 Pro → 无限保存]   │
│                                    │
│  Pro 还包括：                       │
│  · 无限实验                         │
│  · 自定义参数                       │
│  · 导出全量数据                     │
│  · API 访问                        │
│                                    │
│  [¥29/月 立即升级]  [以后再说]       │
└────────────────────────────────────┘
```

**原则**：
1. 免费额度用完 → 提示但**不阻断**当前功能
2. 付费按钮 → 跳转定价页（不弹窗打断）
3. 降级不删数据（只读模式）
