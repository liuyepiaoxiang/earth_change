# v4.1 互动体验升级计划

**Goal:** 从「被动观看」升级为「主动探索」——事件驱动叙事 + 实时反馈 + 微交互。

**核心理念：** 时间轴拖动是「输入」，但用户还需要「输出」——里程碑事件让变化可感知。

### 1. 里程碑事件流（核心——让时间轴「会说话」）
- 引擎纯函数 `milestoneEvents(sim)` → 按年份生成事件列表：
  - 首次超过 1.5°C / 2°C / 3°C / 4°C
  - 首个城市被淹 / 首个百万人口城市被淹 / 前 10 城
  - 海冰夏季无冰年（面积 < 1M km²）
  - 冻土碳释放 > 10% / > 30%
  - 海平面超过 0.5m / 1m / 2m / 5m
  - 群系改变 > 30%
  - pH < 7.8 / < 7.7
- Web：播放/拖动时到达事件年份 → **弹出通知卡片**（图标 + 标题 + 描述 + 数值）
- 时间轴上显示事件刻度点（hover 预览）

### 2. 事件日志流（News Ticker）
- 抽屉新 tab「大事记」：按时间倒序的事件列表，点击跳转到该年份
- 每个事件有 emoji 图标 + 类别颜色

### 3. 微交互增强
- 城市点 hover → 即时 tooltip（名称/当前温度/淹没状态）
- 海洋/陆地任意点点击 → 格点信息卡（温度/降水/群系）
- 播放按钮改为可调速（1×/5×/20×/60× 年/秒）

### 4. 情景竞赛模式（Race）
- 「竞赛」tab：两个情景并排曲线 + 阈值年对照表（已有对比升级版）
- 实时温度赛跑条：当前年两情景的 ΔT 水平条 + 差值标注
