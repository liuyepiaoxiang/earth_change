## F14 温度连续覆盖层与等温线（v1.2 演进，替代 5° 点云）

| 项目 | 说明 |
|---|---|
| 动机 | 用户问「点云换等温线是否更好」——直接换等温线在 Pattern Scaling 场上是水平直线（ΔT 仅随纬度变），会暗示不存在的经向结构；正确解法是**连续色场覆盖 + 等温线标注** |
| 实现 | `buildTempLut`（lib/colormap.ts）：纬度带**锚点线性插值**连续化 Π(lat) → 1×512 RGBA LUT（含每 1°C 等温线深色纬线与 0.78 覆盖透明度）→ DataTexture → shader `uTempLut` 采样（uTempReady 门控）；随 ΔT 全局值重建（512 像素 CPU 微秒级） |
| 效果 | 点阵噪声消失、底图透出、等温线清晰、2592 个 mesh → 0 |
| 异常 | LUT 未就绪由 uTempReady 门控；色域外钳制；纬度端点钳制 |
| 测试映射 | `colormap.test.ts` F14 组（4 条：插值/LUT 同源/等温线存在/ΔT 联动）；e2e R1（温度场开关） |

## F05 淹没模拟 shader

## F11 海冰面积与冰-反照率诊断（v1，V1-02，ADR-001）

| 项目 | 说明 |
|---|---|
| 目标 | 海冰范围与冰-反照率反馈回路（L2）的诊断式量化，UI 直接消费 |
| 输入 | `seaIceArea(ΔT)`；`surfaceAlbedo(areaIce, area0)`；`iceAlbedoFeedback(Δα, λ)` |
| 流程 | logistic 均衡面积（锚点 1850≈8.9/+1.2°C≈7.4/+4°C≈1.2 M km²）→ 线性反照率（kᵢ=0.03/M km²）→ 辐射当量 ΔF = −(S₀/4)(1−c)Δα |
| 输出 | MetricsBar「海冰」指标（含不确定性区间：温度 p90 → 海冰 p10） |
| 异常 | logistic 渐近不触界 → 面积钳制 [0, A₀]；雪被/植被项留 v2（缺省 0） |
| 测试映射 | `engine/equations/seaice.test.ts`（6 条：锚点/单调/线性/符号）；一致性测试（注册 ⇔ impl:v0，outputs 覆盖规则） |

## F13 可视化设计规范（信雅达，v1）

| 项目 | 说明 |
|---|---|
| 信 | ΔT 色阶改为**感知有序的发散色阶**（ColorBrewer RdYlBu 反转系，0°C 近白中性锚点）——取代早期 hue 旋转彩虹（中段绿/黄引导误读、色盲不友好、与异常值语义不符）；端点钳制 [−3, +8]°C |
| 达 | 真实 **Colorbar** 组件：色标渐变 + 刻度（0/1/2/4/6/8）+ 基线说明 + 城市点/淹没/海冰语义行 + **数据出处与模型版本标注**（NASA GISTEMP · WorldClim · GeoNames · v0.1.0 · G1–G5）；色阶 stops 由 `lib/colormap.ts` 单一事实源同时驱动 3D 点云与 Colorbar——杜绝图例与实际色标漂移（旧图例曾写 +5°C 而代码钳 6°C） |
| 雅 | `lib/design.ts` 设计令牌（panel/text/accent/radius）统一 LayerControl/CityPanel/Colorbar 面板样式，深色主题下克制精致 |
| 异常 | 色域外钳制端点色；0°C 中性近白与底图对比由亮度检验保证（单测） |
| 测试映射 | `lib/colormap.test.ts`（7 条：锚点精确/亮度单峰/端点钳制/hex 与渐变同源）；`MetricsBar.test`；e2e 全套回归（S3 淹没像素统计不受色阶变更影响——flood 色未变） |
