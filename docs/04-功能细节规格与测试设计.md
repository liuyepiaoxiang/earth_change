# 04-功能细节规格与测试设计

> 每个功能一张卡片：目标 / 输入 / 流程 / 输出 / 异常 / 测试映射（映射到真实测试文件与用例名）。异常规则均已在测试或手工冒烟中覆盖。

## F01 `/api/simulate` 情景模拟 API

| 项目 | 说明 |
|---|---|
| 输入 | query：`scenario`（4 SSP 之一）、`horizon`（2026–2500 整数） |
| 流程 | zod 解析 → 非法 400 JSON → `runScenario(scenario, horizon)` → JSON 响应 |
| 输出 | SimResult（schemaVersion=1、years、metrics.tempAnomaly/co2/seaLevel×5），`Cache-Control: immutable` |
| 异常 | 非法参数 400；horizon 越界 400 |
| 测试映射 | `apps/web/lib/simulate-query.test.ts`（合法/非法/边界）；浏览器 curl 400 实测（05 §5 冒烟 S1） |

## F02 时间轴与指标插值

| 项目 | 说明 |
|---|---|
| 输入 | year ∈ [2026, 2500] 整数（range input） |
| 流程 | `useSimulation` 动态 import 引擎 → 按情景缓存 SimResult → `metricsAt(sim, year)` 线性插值（越界钳制端点） |
| 输出 | MetricsSnapshot（year/tempAnomaly/co2/seaLevel×5）驱动 MetricsBar、GlobeView、CityPanel |
| 异常 | 空序列返回 null → UI 显示"—"；引擎加载失败显示错误文本 |
| 测试映射 | `apps/web/lib/sim.test.ts`（中点插值/非整数/钳制/端点/空序列）；`scenario.test.ts`（驱动插值钳制） |

## F03 温度点云层

| 项目 | 说明 |
|---|---|
| 输入 | snapshot.tempAnomaly、warming_pattern_lat.csv（8 纬度带 amp） |
| 流程 | 72×36 网格点 → `localDTs(dtGlobal, lat, bands)` → `tempColor` 色阶（0–6°C 线性映射色相 220→0，通道钳制） |
| 输出 | react-globe.gl pointsData（2592 点，高度 0.008，半径 1.9°） |
| 异常 | pattern 为空回退引擎内置 DEFAULT_WARMING_PATTERN；dt<0 与 >6 钳到色阶两端 |
| 测试映射 | `loaders.test.ts`（纬度带数据校验）；`scenario.test.ts`；色阶经 Node 数值验证（00 文档 FLOW-003） |

## F04 城市点层与城市面板

| 项目 | 说明 |
|---|---|
| 输入 | cities_top500.csv（name/country/lat/lon/elevation/population/tbase/pbase）、当前 snapshot |
| 流程 | 点大小 ∝ √(pop/maxPop)，高度 = (高程 − SLR) 归一（淹没点压平）；点击 → CityPanel：`localDTs`、`tbase+ΔT`、`scaledPrecip`、`classifyBiome`、`isCityFlooded` |
| 输出 | 500 城市点 + 面板数据 |
| 异常 | 全民非淹没时面板显示"未淹没"；pattern 空回退默认带 |
| 测试映射 | `loaders.test.ts`（城市 300–600 行、字段范围）；引擎 downscale.test.ts（五函数单测） |

## F05 淹没模拟 shader

| 项目 | 说明 |
|---|---|
| 输入 | elevation_5min.png（RGB 打包 uint16，米，0=海洋，4320×2160）；precip_5min.png（同构，年降水 mm）、snapshot.seaLevel.total |
| 流程 | globeMaterial 注入 onBeforeCompile → 片元采样 vUv 解码高程 → `elev ∈ (0, SLR]`（±30m smoothstep）混入水色；uSlr uniform 随时间轴更新，零重算 |
| 输出 | 逐像素淹没渲染 |
| 异常 | 纹理未就绪时 uDem.value=null（shader 采样黑但不崩）；图层开关只翻 uFlood |
| 测试映射 | manifest.test（高程文件治理）；浏览器冒烟 S3（2100/2300/2500 淹没扩张截图对照）；GLSL 无法单测，编码侧靠打包脚本确定性 |

## F11 海冰面积与冰-反照率诊断（v1，V1-02，ADR-001）

| 项目 | 说明 |
|---|---|
| 目标 | 海冰范围与冰-反照率反馈回路（L2）的诊断式量化，UI 直接消费 |
| 输入 | `seaIceArea(ΔT)`；`surfaceAlbedo(areaIce, area0)`；`iceAlbedoFeedback(Δα, λ)` |
| 流程 | logistic 均衡面积（锚点 1850≈8.9/+1.2°C≈7.4/+4°C≈1.2 M km²）→ 线性反照率（kᵢ=0.03/M km²）→ 辐射当量 ΔF = −(S₀/4)(1−c)Δα |
| 输出 | MetricsBar「海冰」指标（含不确定性区间：温度 p90 → 海冰 p10） |
| 异常 | logistic 渐近不触界 → 面积钳制 [0, A₀]；雪被/植被项留 v2（缺省 0） |
| 测试映射 | `engine/equations/seaice.test.ts`（6 条：锚点/单调/线性/符号）；一致性测试（注册 ⇔ impl:v0，outputs 覆盖规则） |

## F06 图层开关

| 项目 | 说明 |
|---|---|
| 输入 | LayerState 5 布尔位 |
| 流程 | 温度/城市 → points 数组条件重建；淹没/大气 → uniform/altitude；**底图 → 自管材质 map/color 成对切换 + needsUpdate**（绕开 three-globe globeImageUrl 缺陷，见 00 文档 FLOW-004） |
| 输出 | 图层独立显隐，任意组合合法 |
| 异常 | 底图纹理未加载完时切开关：applyBasemap 幂等，纹理就绪回调再应用一次 |
| 测试映射 | 浏览器回归 R1（每层关→开×2 轮 + 全关→全开，截图对照） |

## F10 蒙特卡洛不确定性区间（v1，V1-01）

| 项目 | 说明 |
|---|---|
| 目标 | 量化参数不确定性：对 λ/γ/碳汇/冰冻圈敏感度等 7 个参数在校准值 ±35% 先验跨度内采样，输出逐年 p10/p50/p90 |
| 输入 | scenario、horizon、可选 uncertainty=mc；种子默认 20261011、n 默认 100（钳 2–400） |
| 流程 | mulberry32 种子 PRNG（确定性，G5 例外显式化）→ 逐样本全模拟 → 按年排序取分位 → McResult |
| 输出 | schemaVersion 2 + uncertainty 块；UI：头部 ±区间开关，MetricsBar 显示区间（同情景切换保留中心路径） |
| 异常 | 采样钳制在先验 [min,max]；n<2 抬到 2；CO₂ 浓度外生驱动 → 退化区间自动隐藏 |
| 测试映射 | `engine/mc.test.ts`（10 条：同 seed 逐位复现/分位有序/带展开/物理合理/n 钳制）；`simulate-query.test.ts`（uncertainty 参数）；`MetricsBar.test.tsx`（区间显示与退化隐藏）；e2e S1 扩展点 |

## F12 区域降水 2D 图层（v1，WorldClim 5' 格点）

| 项目 | 说明 |
|---|---|
| 目标 | 区域降水空间格局可视化（此前仅有 eq_52 全球标量缩放），SPEC §5.6「0D→2D 演进」首个落地 |
| 输入 | precip_5min.png（12 个月度格点求和 → 年降水 mm，RGB 打包 uint16，4320×2160） |
| 流程 | 与淹没共用 globeMaterial 注入：uPrec 纹理采样 → pmm/2500 → 干旱棕/半湿黄绿/湿润深绿色阶，mix 0.8 只着色陆地（pmm>0.5）；uPrecOn 图层开关（默认关：与温度点云叠加视觉嘈杂） |
| 输出 | 降水着色的地球图层（撒哈拉棕/刚果·亚马逊深绿） |
| 异常 | 纹理未就绪 uniform 为 null（不崩）；海洋 pmm=0 不着色；淹没色优先于降水色（注入顺序） |
| 测试映射 | manifest.test（precip_5min.png 治理）；e2e smoke.spec R1（第 6 图层循环）；浏览器截图对照（撒哈拉/刚果色阶） |
