# 06-开发环境与实施手册

> 所有命令均在本仓库实际验证过。默认 Windows + Git Bash（pnpm 脚本跨平台，抓取脚本解压步骤用 PowerShell）。

## 1. 前置依赖

| 依赖 | 版本 | 说明 |
|---|---|---|
| Node | ≥ 20 | 内置 fetch；`node -v` 验证 |
| pnpm | 9.x（packageManager 字段锁定 9.15.9） | corepack enable 或 npm i -g pnpm |
| 网络 | 抓取数据时需访问 geodata.ucdavis.edu / data.giss.nasa.gov 等 | 仅 `fetch*.mjs` 需要；开发/构建不需要 |

## 2. 安装与启动

```bash
pnpm install                          # 装依赖（workspace 全量）
pnpm test                             # 全部包 vitest（应全绿，当前 93 条）
pnpm typecheck                        # 全部包 tsc --noEmit
pnpm --filter web dev                 # 开发服务器（predev 自动同步 public 资产）
pnpm --filter web build               # 生产构建（prebuild 同步）
pnpm --filter web start               # 跑生产构建（默认 3000）
npx next start -p 3210                # apps/web 目录下指定端口
```

## 3. 常用开发命令

```bash
pnpm --filter @future-earth/engine test -- golden   # 单测试文件（按名过滤）
pnpm gen:spec                         # YAML → spec-types.ts（提交入库，勿手改）
pnpm calibrate                        # 确定性校准 → params.json + params.gen.ts
npx tsx packages/engine/src/cli.ts --scenario ssp245 --horizon 2500   # CLI 冒烟
```

## 4. 数据更新管道（顺序不可乱）

```bash
node packages/data/scripts/fetch.mjs          # ① 历史序列（NOAA/GISTEMP/GCP）
node packages/data/scripts/gen-forcing.mjs    # ② 自然强迫 + 4 情景 JSON
node packages/data/scripts/fetch-static.mjs   # ③ 城市 + 纬度带（GeoNames/WorldClim/GISTEMP）
node packages/data/scripts/fetch-dem.mjs      # ④ 高程纹理（WorldClim，默认 5'，--res 10 可降）
node packages/data/scripts/gen-bundle.mjs     # ⑤ 全部固化 → datasets.gen.ts（必跑！）
pnpm --filter @future-earth/data test         # ⑥ manifest + loaders 验证
```

规则：任何 `datasets/` 文件变化后必须跑 ⑤，否则 loaders 读的是旧生成模块（详见 00 文档 FLOW-002）。抓取中断残留 `datasets/_tmp/` 可直接删除（manifest 测试已豁免）。

## 5. 环境变量与敏感配置

无需任何环境变量即可开发、构建、部署（无密钥、无数据库、无外部 API）。Vercel 部署零配置。

## 6. 构建与部署

- **CI**（GitHub Actions）：push/PR → `pnpm install --frozen-lockfile → gen:spec → typecheck → test → --filter web build`（node 20，pnpm 版本读 packageManager 字段）
- **Vercel**：导入仓库，Root Directory = `apps/web`，其余默认。静态打包无持久化需求；`/api/simulate` 为无状态函数
- **回滚**：单 commit 粒度 revert；数据回滚 = revert 数据 commit 后重跑 gen-bundle + 测试

## 7. 常见故障

| 症状 | 原因 | 处理 |
|---|---|---|
| manifest 测试红：`expected undefined to be defined` | `datasets/_tmp/` 抓取残留 | 删除 `_tmp/`；脚本正常结束会自删 |
| manifest 校验和不匹配 | 行尾被 CRLF 改写或手改数据 | `git checkout` 该文件；编辑器必须 LF（.gitattributes 已强制） |
| UI 无城市/纬度带数据 | 改了 datasets 但没跑 gen-bundle | 跑 `gen-bundle.mjs` |
| 3210 端口起了旧代码 | 孤儿 next-server 占端口 | 按端口 PID 杀进程（PowerShell Get-CimInstance），勿用进程名通配 |
| 球体全黑（底图开着） | v0 早期外链纹理问题，已本地化 | 确认 public/earth-blue-marble.jpg 存在；再查图层开关 |
| web build 报 node: 内置模块 | workspace 包根入口引入了 node 模块 | 引擎只允许改 `load-spec.ts` 等 Node 专用入口（AGENTS.md 坑清单） |
