> 建立日期：2026-11-12 ｜ 调研方式：子代理联网调研（渠道）+ 领域知识（同类服务）
> 项目画像：浏览器端 3D 地球气候演化模拟器 · 公众科普教育 · TS/Next.js · 中国大陆个人开发者 · 已上线 Vercel · 中英双语 · 开源

## 一、同类服务盘点

### 1.1 直接同类：交互式气候/地球模拟器

| 项目 | 机构 | 形态 | 受众/规模 | 资金模式 | 与本项目差异 |
|---|---|---|---|---|---|
| **En-ROADS** | Climate Interactive（美国非营利） | 浏览器交互模拟器（18 政策滑杆） | 全球政策工作坊/教育，数百万用户体验 | 气候慈善基金会捐赠 + 「按捐赠」培训课程 + 机构引导工作坊 | 最直接对标：他们的模型偏政策杠杆（碳价/税收/能效），本项目偏地球系统演化 + 3D 空间呈现；他们有基金会大盘和成熟方法论 |
| **C-ROADS** | Climate Interactive | 同上（国家尺度谈判模拟） | 联合国谈判/高校 | 同上 | 面向谈判者，不面向公众 |

| **Our World in Data CO₂ Explorer** | Global Change Data Lab（英国非营利） | 数据浏览器 + 图表 | 数千万读者/年 | 捐赠（Gates/Sloan 等）+ 内容授权 | 数据叙事强，无模拟器 |

| **Terra / 地球数字孪生产品**（欧盟 Destination Earth「DestinE」） | 欧盟委员会 | 高分辨率数字孪生（HPC） | 科研/政策 | EU 公共预算（数亿欧元） | 科学定位不同（操作级 vs 教育级）；验证了「数字孪生地球」的公共叙事吸引力 |

### 1.2 方法论同类：简单气候模型（开源）

| 模型 | 语言 | 定位 | 备注 |
|---|---|---|---|
| **FaIR** | Python | 简单气候模型（IPCC 用），emit-driven | 学术标准；本项目 TS 实现是同类思想 |
| **MAGICC** | Fortran | 半经验简单气候模型 | 授权受限 |
| **ESCIMO** | 简化 Earth System Model | 生物圈+气候快慢系统 | 概念接近本项目耦合箱 |
| **HECTOR** | C++ | 开源简单碳气候模型（PNNL/JGCRI） | 可对照校准 |
| **two-layer EBM（Geoffroy 2013）** | 多语言 | IPCC AR6 用的两层能量平衡 | 本项目核心即此家族 |

### 1.3 中国国内同类

| 产品 | 形态 | 备注 |
|---|---|---|
| 中国气象局公众产品（天气/气候大屏） | 可视化大屏 | 观测/预报为主，无情景演化 |
| 各类「碳中和」数字大屏（阿里/华为/地方） | 数据大屏 | 展示型，无模拟引擎 |
| 「双碳」模拟计算器（学术网页） | 简单计算器 | 无 3D/时间演化/公众产品化 |
| 科普馆实体展项（科技馆地球球幕） | 展览 | 线下，无开源在线模拟器——**空白点** |

**差异化定位结论**：全球范围内，**「开源 + 浏览器 3D + 情景演化 5-500 年 + 城市级降尺度 + 中英双语 + AI 问答」的组合尚无直接对标产品**。En-ROADS 最接近但偏政策杠杆交互；本项目独特性在地球系统空间呈现（淹没/温度场/城市）。可持续运营的最大参照系是 Climate Interactive（基金会+教育服务）与 Nullschool（个人维护）两个极端。

## 二、资金渠道与可持续模式（子代理联网调研，2026-11 核实）

> 完整调研由子代理完成（34 次检索核验）。核心结论：**个人身份下现金资助的现实选项少但存在**——最可行是 NLnet（€5k–50k，全球个人可申请）+ 中国本土赛事/公益招募（SEE 创绿家、AI for Good、UNDP 青年赛）；GitHub Sponsors 大陆无法收款；气候慈善巨头全部组织导向且多为邀请制；长期可持续更可能来自**教育场景服务 + 月捐**组合。

### 2.1 直接可行（个人可申请）

| 渠道 | 金额 | 周期 | 适配 |
|---|---|---|---|
| **NLnet 基金会（荷兰）⭐推荐** | €5k–50k | 滚动，双数月 3 日截止（下次 2027-01-03） | 全球个人可申请，FOSS 即可；建议以「开源公共品 + 科学教育工具」投 Research & Higher Education Technology Fund；有开放地图先例（Protomaps） |
| GitHub Secure Open Source Fund | $10k/项目 | Session 滚动 | ⚠️ 须 GitHub Sponsors 支持地区（大陆不在，港澳可）；定位安全强化，契合度弱 |
| 爱发电等国内月捐 | 不限 | 即时 | 零门槛打底，天花板低 |
| AI for Good 公益黑客松 2026（恩派 NPI） | 最高 ¥10k + 影响力投资对接 | 2026-01 已发布议题 | 个人/小队可报，阿里生态背景 |
| SEE 基金会「创绿家」 | 万级（历史报道） | 年度招募（2026 届待发布） | 初创环保公益团队；纯数字教育项目需向项目组确认 |
| UNDP 驻华青年创客挑战赛 | 孵化+对接 | 年度 | 历届含气候主题，2026 届待发布 |
| 国际小额黑客松（IEEE ClimateChain 等） | $2.5k–3k+ | 滚动 | 简历友好 |

### 2.2 需要合作单位或注册实体

| 渠道 | 量级 | 个人门槛 | 解锁路径 |
|---|---|---|---|
| Energy Foundation China（能源基金会） | 单项目最高 $300k，对华年 $30M | 只资助机构 | 注册民非 / 与既有 NGO 合作 |
| ClimateWorks / Quadrature / Bezos Earth Fund | $M 级 | 全部组织导向，多为邀请制 | 通过 CEGA《气候慈善指南》定位中国愿意资助公众气候教育的资助方 |
| 腾讯 SSV / 碳寻计划 | 亿元级（硬件赛道） | 无个人通道 | SSV 数字教育提供工具资源非现金 |
| NSFC 青年基金 / 国家重点研发 | ¥30–万级 | 需依托单位+博士学位 | 在职读博/博士后挂靠 |

### 2.3 商业化路径（参照 En-ROADS 模式）

| 路径 | 评估 |
|---|---|
| **气候教育工作坊**（国际学校/科技馆/企业 ESG） | 最直接现金流；B2B 需发票 → 个体工商户 |
| 教育场景许可（课堂模式/作业系统） | 开源核心 + 商业服务双轨 |
| 引擎嵌入/API 授权（托管+更新+支持） | engine 纯 TS 无浏览器依赖，技术可行 |
| 月捐（爱发电 + Open Collective OSC 海外） | 打底；OCF（环境类 fiscal host）已于 2024 解散，注意 |
| 影响力投资对接 | 经黑客松/UNDP 赛事，项目偏公益，长尾选项 |

### 2.4 行动优先级

1. **立即**：爱发电月捐上线；投 NLnet（2027-01-03 截止，€5k–50k）
2. **2026 冬–2027 春**：AI for Good 公益黑客松 2026；SEE 创绿家 2026 招募；UNDP 青年赛 2026 届
3. **中期**：注册个体工商户 → 包装「气候模拟工作坊」推向国际学校/科普场馆；用 CEGA《气候慈善指南》锁定 2–3 家资助方
4. **如考虑组织化**：注册民非或挂 NGO 合作 → 解锁 EF China 与腾讯 SSV 生态
5. **放弃**：Prototype Fund（德国居住）、Sovereign Tech（定位）、ClimateWorks/Quadrature/Bezos（邀请制组织导向）、NSFC/重点研发（无单位）

### 2.5 主要不确定项

① GitHub Secure OSS Fund 对大陆居住者资格；② SEE 创绿家是否接受纯数字教育项目；③ ClimateLaunchpad 中国赛区是否存在；④ Google GARA 大陆资格；⑤ CCAI 2026–27 新周期是否开放。

## 三、结论

1. **差异化定位成立**：「开源 + 浏览器 3D + 5-500 年情景演化 + 城市级降尺度 + 中英双语 + AI 问答」无直接对标；最接近的 En-ROADS 偏政策杠杆、Nullschool 偏实时气象。
2. **资金现实**：个人身份的国际现金资助首推 NLnet；国内现金来自赛事与 SEE 创绿家类公益招募；气候慈善巨头均需组织实体。
3. **可持续路径**：参照 En-ROADS「免费模拟器 + 付费教育服务」模式——先以工作坊/学校服务产生现金流，同时以 NLnet/月捐覆盖开源维护成本；组织化（民非/挂靠）是进入更大盘子（EF China $300k 级）的钥匙。
