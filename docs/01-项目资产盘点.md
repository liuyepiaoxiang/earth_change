## 1. 目录结构与技术栈

```

├── apps/web/            Next.js 14 App Router（Vercel 部署单元），react-globe.gl + three
```

## 3. 可复用能力（新增功能必须优先复用）

- 规格门禁：改方程的 YAML → gen:spec → 注册 → 测试链路（防漂移）
- 数据管道：`fetch*.mjs` → `datasets/` + manifest → `gen-bundle.mjs` → loaders（loaders.test.ts 兜底）
- 校准回路：`pnpm calibrate`（确定性，重跑结果逐位一致，指纹预计算进 params.gen.ts）
